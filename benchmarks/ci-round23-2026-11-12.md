# Smaller stripped dependency archives, November 12, 2026

When the final Go link discards DWARF, drvgo now passes `-dwarf=false` to its
package compilers. This avoids generating and transferring debug information
that the executable will never retain. The optimization applies to tested SDKs
and follows Go's actual linker flag grammar: `-w`, `-s`, double dashes, boolean
values and repeated flags. Explicit `-w=false` overrides `-s` in either order.
Flag-like operands and generated file bodies are not mistaken for flags.
Experimental SDKs retain their original compiler behavior.

No default application linker flag changes. Ordinary debug exports preserve all
3,899 generated files across the fixture and UPM comparisons. Stripped builds
use separate archive recipes, so debug and stripped dependency caches cannot
share these outputs. Automatic action IDs and binary bytes can change; explicit
build IDs and Go build metadata are preserved. Runtime function/line tables and
inline stack frames remain available.

Implementation `63cdc7a` is compared with main `8ee15a4`; `aceaf7a` adds only
previous-plan transition tests. The CI baseline checkout `4bb7b6d` has the same
tree as main. [Raw results and validation](ci-round23-2026-11-12.json) include
commands, SDK paths, output identities, per-trial timings and cache payloads.

## Dependency rebuilds and transfer sizes

| Workload | Packages | Median before | Median after | Improvement | Package zstd before | Package zstd after |
|---|---:|---:|---:|---:|---:|---:|
| Fixture | 67 | 4.045 s | 3.742 s | 7.5% | 8,753,369 B | 6,851,020 B |
| UPM | 554 | 45.701 s | 43.241 s | 5.4% | 84,079,944 B | 69,879,582 B |

The measurements recompile every package using `nix-build --check`, with warm
SDK, sources and dependency outputs. Five alternating fixture pairs and three
UPM pairs, plus warmups, complete twenty reproducibility checks. Both graphs
use `-s -w -buildid=drvgo-probe`. A prototype added the compiler flag
unconditionally; the final, conditional exporter produces byte-identical
complete exports for these two workloads (732 and 3,167 files). Worker recipes
from the measured prototype therefore match the final implementation exactly.

Copying all package outputs to a fresh local zstd-level-3 binary cache saves
**1,902,349 bytes (21.7%)** for the fixture and **14,200,362 bytes (16.9%)** for UPM.
Package NAR sizes fall from 35,265,528 to 26,118,816 bytes and from 329,222,800 to
260,626,784 bytes. Complete package-output closures retain 75 and 565 paths;
their compressed totals fall from 23,245,947 to 21,343,598 bytes and from
101,279,921 to 87,079,559 bytes. These are output payload measurements, not
planner inputs or measured network transfer times.

Final executable sizes remain 1,698,160 and 28,258,304 bytes in these examples,
but their hashes and some code/data sections change, even with the same custom
build ID. The comparison does not claim byte-identical executables. Initial
realization timings had unequal cache warmth and are excluded from speed claims.

## Fresh planning with warm package outputs

Seven alternating pairs plus warmups cover eight configurations and 128 dynamic
builds. All default/debug builds retain their original package output. Each
stripped variant is stable across its own trials, while before/after outputs
differ as expected. Each resulting fixture or UPM command is also run.

| Link mode | Workload | Nested evaluator | Before | After |
|---|---|---|---:|---:|
| debug | fixture | nix | 0.850 s | 0.853 s |
| debug | fixture | iets | 0.661 s | 0.666 s |
| debug | upm-prepared | nix | 2.456 s | 2.496 s |
| debug | upm-prepared | iets | 2.064 s | 2.052 s |
| stripped | fixture | nix | 0.884 s | 0.868 s |
| stripped | fixture | iets | 0.663 s | 0.664 s |
| stripped | upm-prepared | nix | 2.485 s | 2.490 s |
| stripped | upm-prepared | iets | 2.054 s | 2.065 s |

Total medians range from -1.8% to +1.6% relative to the baseline.
Treat cached CI latency as effectively unchanged; the gains are dependency
recompilation and archive payloads. The outer evaluation client is Nix. Nested
iets is upstream PR #3 at `69883a64bfb0d9a95dce253dae304878e07b076e`, using one
worker with caches and fallback disabled. The separate iets suite also tests
iets as the outer client, nested planning and direct dynamic outputs.

All timings use Go 1.26.5, Nix four jobs/two cores, strict sandboxing, no sandbox
fallback, IFD disabled and substitutions disabled. UPM is revision
`35a76c282507fb942445c0ee98427b3d1ef772bc`, package `./cmd/upm`, with a prepared
module cache. SDK downloads, cold filesystem caches and network latency are
outside these measurements.

```sh
python3 scripts/benchmark-build.py --before /path/to/before-export \
  --after /path/to/after-export --runs 5
python3 scripts/benchmark-ci.py --before /path/to/baseline \
  --after /path/to/current --source /path/to/project --ldflags='-s -w' \
  --runs 7 --nix-option sandbox true --nix-option sandbox-fallback false \
  --nix-option substituters '' --nix-option always-allow-substitutes false
```

## Planner input cost

Complete planner inputs grow by 9,856 NAR bytes and 3,630 compressed bytes,
including raw derivation metadata. Compiler, linker, native and full worker
toolchain derivations are identical. No extra tool or cache dependency is added.
The packaged CLI remains 3,387,216 bytes; its bytes change.

## Validation

Unit tests and vet pass. New integration tests pass on Go 1.25.12, 1.26.5 and
1.26.6: native-Go differential stack frames, inline calls, debug stacks, crypto
self-tests, build metadata, custom build IDs, debug-section presence/absence,
`-s -w=false` and stripped test binaries. The full Go 1.26.5 compatibility suite
passes thirteen differential cases, including stripped external assembly,
race-enabled cgo and native objects, plus interfaces/early-cutoff layouts,
dynamic builds, prepared modules, source edits and runtime references.

The full iets suite passes outer/nested builds and direct outputs, stripped and
debug-preserving variants, optional tests, invalid-source validation, runtime
references and previous-plan reuse. Additional previous-plan tests switch from
debug to stripped archives and back; Nix and iets both agree with fresh plans.
Linux x86-64, Linux ARM64 and macOS ARM64 CI across all three SDKs remains the
merge gate.
