# Compact tool inputs for explicit internal links

The Linux amd64 internal-link tool closure falls from **137.62 MB to 26.82 MB
compressed**, an **80.5% reduction**. Automatic linking keeps its existing
behavior. Cached CI latency and CLI bootstrap remain effectively flat.

Measurements use Go 1.26.5, the repository's pinned Nixpkgs, and iets PR #3 at
`69883a64bfb0d9a95dce253dae304878e07b076e`. The baseline is
`0c238cf690aa95749188a076b3a7b8343e2d65ef`; implementation and measurement commits,
commands, paths, hashes, and individual runs are in the
[raw results](ci-round27-2026-11-12.json). Sizes use decimal MB and local zstd
level 3 binary caches; this does not measure network transfer time.

## Change and scope

An explicit `-linkmode=internal` previously selected the full native toolchain.
Go's internal linker usually needs no compiler executable, but can ask it for
runtime libraries. Removing the compiler outright broke the Linux race probe
with an unresolved `__popcountdi2` symbol.

A small compiled helper now answers the pinned compiler's three applicable
runtime-library queries. It returns unchanged copies of `libgcc`,
`libc_nonshared`, and `libssp_nonshared` when available, and preserves responses
for absent libraries. Unsupported commands fail. Linux ELF search paths retain
only the helper's actual runtime dependencies. The existing Go replay runner,
compiler, linker, and native tool bundles are unchanged.

Selection requires one explicit internal-link action and the default compiler
query command, with correct handling of repeated flags and flag operands.
Experimental Go versions and custom compiler commands retain the old selection.
Pure Go internal links use the existing Go link bundle. Units that compile cgo
sources keep the full native compiler. Toolchains without the optional new role
fall back to their native bundle.

This does not force internal linking onto automatic builds. The existing cgo
fixture and UPM reject forced internal linking even with the original compiler
bundle; those programs still need their normal external link behavior.

Portable empty-test exports also now include the archive implementation and
patch needed to recreate their default toolchain. A regression test forces
evaluation of the exported recipe rather than relying on existing local paths.

## Tool and planner payloads

| Closure | Before paths | After paths | Before NAR bytes | After NAR bytes | Before zstd bytes | After zstd bytes |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| Eligible internal root link | 33 | 10 | 434,799,512 | 83,311,552 | 137,619,958 | 26,819,690 |
| Full discovery toolchain | 39 | 41 | 666,598,520 | 669,911,936 | 199,933,925 | 201,415,988 |
| Complete Nix planner inputs | 929 | 932 | 324,434,264 | 324,463,272 | 93,696,694 | 93,707,025 |
| Complete iets planner inputs | 871 | 874 | 210,276,928 | 210,305,936 | 54,787,403 | 54,797,734 |

The tradeoff is **1,482,063 additional compressed bytes** in the complete
discovery toolchain, including the copied runtime archives. Dynamic planner
inputs add **10,331 compressed bytes**; they carry the new recipes without
realizing the runtime bundle. Existing compile, link, and native closures have
identical store paths and sizes.

These root-link figures exclude compiled package archives. A cold build that
also compiles cgo dependencies still needs their native compiler. The reduction
helps an eligible final-link worker whose native dependencies are cached.
Pure Go explicit internal links instead use the existing 25,338,285-byte
compressed Go link closure.

## CI and bootstrap measurements

Each cached-CI case uses seven interleaved measured pairs plus a warmup pair,
with fresh planners and warm package outputs: **64 builds total**. Sandboxing
is required, IFD and substitution are disabled, and local measurements run
sequentially. The net workload explicitly selects internal linking; the fixture
retains automatic linking. Both use explicit build IDs for artifact comparisons.

| Workload / nested evaluator | Before median total | After median total | Change |
| --- | ---: | ---: | ---: |
| Fixture / Nix | 0.863 s | 0.870 s | +0.8% |
| Fixture / iets | 0.655 s | 0.663 s | +1.1% |
| Net internal link / Nix | 0.868 s | 0.865 s | -0.3% |
| Net internal link / iets | 0.667 s | 0.681 s | +2.1% |

This is a payload reduction, not a demonstrated cached-CI speedup. The fixture
keeps the exact output path. Net's final link changes path, while its executable
remains byte-identical. Outputs stay stable within each revision and agree
between Nix and iets.

Twelve fresh CLI package builds, including all unit tests and vet, give median
totals of **6.168 s before and 6.208 s after** (+0.6%). The stripped CLI grows
from 3,395,408 to 3,403,600 bytes. Six fresh helper rebuilds with cached compiler
inputs, including Nix's reproducibility check, pass with a measured median of
**0.150 s** after the warmup. This does not include downloading compiler inputs.

## Validation

- Unit tests, normal and integration vet, and inline default-toolchain
  resolution pass. Parser tests cover repetition, operands, custom compilers,
  heredocs, malformed traces, explicit `-libgcc`, and experimental SDKs.
- All **755 package recipes** across ordinary assembly, fixture, UPM, and net
  exports remain identical. Three explicit-internal cases change only their
  final link action; every source hash and replay script remains identical.
- Compiler-query outputs preserve archive bytes or absent-library responses.
  Pure, cgo, and race commands run successfully; final executables are identical
  to the original compiler-bundle fallback with explicit build IDs.
- The complete local Go 1.26.5 compatibility suite passes, including the three
  new internal-link cases through standalone, compact-archive, content-addressed,
  and dynamic builds. This full run used the first helper before removing its
  unused ELF search path. The final helper then passed the focused query,
  executable-identity, fallback, and portable-empty-export tests, the full iets
  suite, and all 64 cached-CI builds.
- iets PR #3 passes outer/nested evaluation, direct outputs, cache reuse,
  invalidation, optional tests, runtime references, and internal links with and
  without race instrumentation. Fallback and the tracing cache are disabled.
- The compatibility matrix requires the new tests across all three pinned Go
  SDKs on Linux amd64/arm64 and Apple Silicon macOS, and reports native/internal
  tool NAR sizes. Cross-platform CI must pass before merging this change.
