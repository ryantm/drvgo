# Native queries shrink optional iets planner inputs

Measured on Linux amd64 with Go 1.26.5 on November 11, 2026. Baseline
`4047f4d075b4f353627045ccf400d6c7ecdd97de`; implementation
`78d95c4ee47a84038de0153d0a653e436889d8b0`.
[Raw samples, exact commands, closures and validation](ci-round13-2026-11-11.json).

The optional static iets planner now needs **40,827,757 fewer compressed bytes**
and **56 fewer store paths**. Native read-only daemon queries replace Nix CLI
subprocesses during recursive export, allowing the iets planner to omit the
Nix package. Worker recipes and Go package outputs remain identical.

## Behavior and validation

The existing native NAR reader's protocol 1.21 handshake is shared with
`QueryValidPaths` and `QueryPathInfo`. These operations cannot build, substitute,
register paths or change store settings. The recursive daemon still determines
which paths are visible. Its deliberately censored deriver metadata continues
to require an explicit toolchain; drvgo never substitutes another compiler.
Plain absolute Unix socket URLs use native queries. Other transports and URLs
with options or escapes retain the existing CLI behavior.

A failed, truncated or invalid runtime-reference query fails the export. It
cannot fall back to a different store or silently lose references. Unit tests
check wire requests, bounded replies, unexpected/duplicate paths, malformed
metadata and propagated errors. Existing NAR-copy tests continue to pass.

A new real sandbox check removes both `nix` and `nix-store` from PATH, confirms
that declared runtime data remains referenced, and excludes an unrelated path
that exists in the host store. It also checks missing paths, censored toolchain
metadata and a broken socket: the failed export publishes no graph. This check
runs once per platform in the default-Go compatibility job. Ordinary exports
through `daemon` and a plain Unix URL retain identical runtime references,
compiler context and package derivations.

Unit tests, vet, the complete local Go 1.26.5 compatibility suite and the full
static iets integration suite pass. Coverage includes outer/nested builds,
public flake helpers, direct `outputOf`, native/race/test modes, invalidation,
runtime closures and invalid Go/C code after a cached empty-test result.
Additional flake-helper builds preserve package identity in both optional
compiler-archive modes. The complete Linux amd64/arm64 and Apple Silicon matrix
remains required before merge; its final status is recorded on the PR.

The protocol implementation was checked against pinned Nix 2.34.8's
[`daemon.cc`](https://github.com/NixOS/nix/blob/2.34.8/src/libstore/daemon.cc),
[`restricted-store.cc`](https://github.com/NixOS/nix/blob/2.34.8/src/libstore/restricted-store.cc)
and worker protocol serialization. No daemon configuration or sandbox rules
were changed.

## Planner inputs

Actual complete planner closures, including raw recipe metadata, copied to a
local zstd level 3 binary cache:

| Workload | Planner | Before compressed bytes | After compressed bytes |
| --- | --- | ---: | ---: |
| Cgo fixture | Default Nix | 97,467,066 | 97,472,107 |
| Cgo fixture | Static iets | 102,597,609 | 61,769,852 |
| UPM, prepared modules | Default Nix | 251,486,086 | 251,491,127 |
| UPM, prepared modules | Static iets | 256,616,629 | 215,788,872 |

The default Nix planner adds 19,464 NAR bytes and 5,041 compressed bytes for
the native query code, with the same path count. The iets path drops
117,935,024 NAR bytes and 40,827,757 compressed bytes, with 56 fewer paths.
These are payload sizes, not network timings. iets remains opt-in; this round
validates its use on Linux amd64 with upstream's static PR #3 package at
`69883a64bfb0d9a95dce253dae304878e07b076e`.

## Build and evaluation time

Five alternating trials plus excluded warmups, using fresh planners and warm
tools, modules and package outputs. Both sides use strict sandboxing, IFD
disabled, four jobs/two cores, and no remote cache lookups. The same evaluator
package and dependency preparation mode are used on both sides. All local
tests and closure copies finish before timing starts.

| Workload | Nested evaluator | Before total | After total | Reduction |
| --- | --- | ---: | ---: | ---: |
| Cgo fixture | Default Nix | 0.895 s | 0.861 s | 3.8% |
| Cgo fixture | Static iets | 0.874 s | 0.675 s | 22.8% |
| UPM, module proxy | Default Nix | 3.411 s | 3.406 s | 0.2% |
| UPM, module proxy | Static iets | 3.156 s | 3.031 s | 4.0% |
| UPM, prepared modules | Default Nix | 2.551 s | 2.509 s | 1.6% |
| UPM, prepared modules | Static iets | 2.238 s | 2.132 s | 4.8% |

Every before/after trial resolves to the same Go package output. These timings
include outer Nix evaluation, planning and forwarding, with no cold compilation
or network transfers. Small changes on the default Nix path should be read as
approximately unchanged; the larger improvement comes from omitting the Nix
input when iets is selected.

Fifteen alternating outer-helper evaluations, without builds, using the same
static iets clients on both revisions with tracing and fallback disabled:

| Workload | Nested evaluator | Nix before → after | iets, 1 worker | iets, 4 workers |
| --- | --- | ---: | ---: | ---: |
| Cgo fixture | Default Nix | 393.4 → 394.4 ms | 244.8 → 242.7 ms | 128.7 → 128.3 ms |
| Cgo fixture | Static iets | 390.3 → 207.8 ms | 244.5 → 74.7 ms | 130.4 → 64.6 ms |
| UPM, module proxy | Default Nix | 413.2 → 420.7 ms | 274.5 → 272.6 ms | 130.2 → 133.3 ms |
| UPM, module proxy | Static iets | 410.6 → 344.7 ms | 274.6 → 146.3 ms | 134.4 → 88.8 ms |
| UPM, prepared modules | Default Nix | 408.1 → 413.8 ms | 277.2 → 273.8 ms | 133.5 → 134.6 ms |
| UPM, prepared modules | Static iets | 410.1 → 315.0 ms | 274.3 → 100.9 ms | 134.4 → 70.7 ms |

Each client returns the same derivation for a given revision and configuration.
The iets planner no longer forces evaluation of the Nix package. Module-proxy
workloads still evaluate `buildGoModule`; prepared dependencies avoid that work.
Integration-run timings are recorded separately and are not benchmark claims.

## Reproduction

```sh
python3 tests/native-store-queries.py
python3 tests/iets.py --iets /nix/store/...-iets/bin/iets --runs 1
python3 scripts/benchmark-ci.py --before /path/to/baseline --after . \
  --source /path/to/upm --package ./cmd/upm \
  --module-cache /nix/store/...-drvgo-module-cache \
  --before-iets /nix/store/...-iets --after-iets /nix/store/...-iets \
  --runs 5 --nix-option sandbox true --nix-option sandbox-fallback false \
  --nix-option substituters '' --nix-option always-allow-substitutes false
python3 scripts/benchmark-evaluation.py --before /path/to/baseline --after . \
  --dynamic-source /path/to/upm --package ./cmd/upm \
  --module-cache /nix/store/...-drvgo-module-cache \
  --before-iets /nix/store/...-iets --after-iets /nix/store/...-iets \
  --iets /nix/store/...-iets/bin/iets --runs 15
```

Omit both nested evaluator arguments for the default Nix comparison. Replace
`--module-cache` with `--vendor-hash` for proxy trials. The fixture uses
`tests/fixture`, package `.`, and neither dependency option. Exact pins, store
paths and commands are included in the JSON.
