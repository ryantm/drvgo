# Cold planner inputs and optional tests, November 11, 2026

Baseline: `73997d1`, including the reviewed replay, optional-test, and runtime-reference fixes.
Both sides include PR #9; these measurements supersede the earlier `0ade565` comparison.
Measurements use Linux amd64, an Intel i7-1280P, Go 1.26.5, Determinate Nix
3.24.1 / Nix 2.35.3, and the pinned Nix 2.34.8 inside the recursive planner.
[Raw measurements and validation](ci-round3-2026-11-11.json) accompany this report.

## Fresh dynamic builds

Five alternating before/after trials exclude warmups. Each trial uses a unique
forwarding name, forcing fresh planning and a fresh Go cache while preserving
cached tools and compiled package outputs. Both revisions disable remote cache
queries and IFD. Sandboxing is enabled with fallback disabled.

| Workload, cgo disabled | Before median | After median |
|---|---:|---:|
| Small command importing `fmt` | 0.881 s | 0.886 s |
| Optional package without tests | 3.286 s | 0.617 s |
| Optional package with quoted-tagged external tests | 3.791 s | 1.140 s |

The small command total differs by 5 ms (0.6%); realization is essentially
unchanged. The optional-test cases improve by **81.2%** and **69.9%**
respectively. Outer evaluation stays near 390 ms; realization falls from 2.895
to 0.219 seconds for the empty package and 3.399 to 0.740 seconds for enabled tests. The optimization preserves the compiler
and package replay recipes.

Previously, every optional test candidate compiled and ran a helper importing
`go/build`, even when `go list` already supplied the selected source/test files.
The helper's standard library was compiled afresh inside each recursive planner.
Successful listing now selects the common path directly. Ordinary packages
without tests still run `go test -c -vet=off` to reject import, syntax, type, and
embed errors. Ambiguous/excluded directories retain the selected compiler's
typed `NoGoError` check. No diagnostic-string matching is used.

The excluded-directory path still compiles the helper; its optimization remains
open. These small fixtures isolate selection overhead and do not predict the
cost of validating a large no-test package's dependency graph.

## Cold planner transfer

When `cgoEnabled = false`, the planner now receives the selected Go SDK directly.
The native toolchain remains available to the generated graph by its recipe.
Worker output contexts are restored in the nested evaluator, so planning does
not first fetch those unused outputs. Default/cgo planning still uses the full
toolchain. Generated package dependencies and outputs remain unchanged.

| Complete planner input closure | Before | After |
|---|---:|---:|
| NAR bytes | 768.36 MiB | 399.29 MiB |
| zstd level 3 payload | 235.46 MiB | 118.45 MiB |
| Store objects | 987 | 960 |

The compressed payload is **49.7% smaller**. This includes source and derivation
metadata as well as the actual requested tool outputs. It excludes tools that
only later package builds require. Sizes come from copying both closures to a
fresh local file binary cache; they are not network-transfer timings or a claim
that warm planning is twice as fast. Cache metadata overhead is not included.
The fixture has no external modules; module fetches and later package builds
are outside this transfer measurement.

## Compatibility and iets

All **565 package derivations across nine compatibility cases** are identical
to the corrected baseline. Runtime references legitimately change recipes
relative to `0ade565`; the optimization comparison starts after that fix.
Ordinary and dynamic outputs agree, including cgo-disabled
tests, cgo/race tests, nested commands with custom build IDs, and empty results.
Unit tests additionally cover invalid embeds, conflicting packages, and empty
directories. The existing release/platform/tag selection and hermetic replay
regressions continue to pass. Dynamic mode tests require sandboxing and disable
IFD and sandbox fallback.

Checking the SDK-only planner with a prebuilt `.syso` object exposed a baseline
replay bug: the archive packer could lose the working directory omitted by
cmd/go. Caller-relative object paths are now mapped to their source snapshot;
other elided native directories are restored when needed. A new tenth case
(61 units) agrees with Go and tests the dynamic SDK-only planner. An integration
regression also builds after removing the original source. Existing race-package
recipes remain unchanged. Explicit external linking with cgo disabled continues
to fail as Go requires.

[iets PR 3](https://github.com/replit/iets/pull/3), revision
`69883a64bfb0d9a95dce253dae304878e07b076e`, passes outer and nested planning,
direct `outputOf`, repeat builds, and embedded-file invalidation. New permanent
checks cover SDK-only planners producing empty and quoted-tagged external-test
results, equality with Nix, and rejection of a type error after an empty output
has been cached. Runtime-reference checks additionally cover source literals,
embedded assets, linker flags, explicit inputs, and unused-input exclusion in
outer and nested planners. All four runtime variants resolve to the same
package output. IFD and classic fallback are disabled; the daemon requires
sandboxing with fallback disabled.

| Warm outer wrapper evaluation, 5 trials | Nix | iets, 1 worker | iets, 4 workers |
|---|---:|---:|---:|
| Nix inside planner | 393 ms | 196 ms | 105 ms |
| iets inside planner | 406 ms | 198 ms | 105 ms |

These are current-revision evaluation timings with the tracing cache disabled
and compiled-file cache warm, excluding realization. Evaluation samples run
separately from local compatibility/build benchmarks. They are not before/after
speedup estimates. The cross-platform CI matrix is recorded in the pull request.

## Reproduction

Create a baseline checkout at `73997d1`. Use a source directory containing
`go.mod` and either a small `fmt` command, a plain package, or a plain package
with an external test guarded by `//go:build special`. Exact benchmark fixture
contents are included in the JSON report.

```sh
python3 scripts/benchmark-ci.py \
  --before /path/to/baseline --after "$PWD" --source /path/to/source \
  --cgo 0 --test --allow-empty-tests --runs 5 \
  --nix-option always-allow-substitutes false --nix-option substituters ''
# Add --tags "'special'" for the enabled-test case.
# Omit --test and --allow-empty-tests for the command case.

# Obtain each planner .drv with nix-instantiate -A planner against the same
# source and cgoEnabled=false, using the corresponding checkout's helper.
python3 scripts/benchmark-planner-closure.py \
  --before /nix/store/BASELINE-result.drv.drv \
  --after /nix/store/CURRENT-result.drv.drv

python3 tests/iets.py --iets /nix/store/IETS/bin/iets --runs 5
```
